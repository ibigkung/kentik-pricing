FREQUENTLY ASKED QUESTIONS
คำถามที่พบบ่อยก่อนตัดสินใจเลือกแผน
ไม่ได้ครับ Kentik ใช้ระบบ Annual Contract เท่านั้น ราคา Pro เริ่มต้นที่ $2,000/เดือน = $24,000/ปี แต่มีตัวเลือก Multi-year payment ที่อาจได้ราคาดีกว่า — ติดต่อทีม Sales เพื่อหารือเรื่องเงื่อนไขการชำระ
ได้ครับ ทั้ง FPS และ Synthetics Credits มีตัวเลือก Scale เพิ่ม Kentik จะแนะนำ tier ที่เหมาะสมตาม actual usage — ติดต่อเพื่อรับใบเสนอราคาสำหรับปริมาณที่ต้องการจริง
ได้ครับ Kentik รองรับ Upgrade Path จาก Pro ไป Premier ได้ตลอด ติดต่อ Account Manager เพื่อดำเนินการ ทั้งนี้ราคาจะ pro-rate ตามระยะเวลาที่เหลือของสัญญาปัจจุบัน
ราคาที่แสดงบนเว็บเป็น USD สำหรับ US market ราคา International (รวมถึง Thailand/APAC) อาจแตกต่าง ต้องติดต่อ Kentik Sales โดยตรงเพื่อรับ Quote ที่ถูกต้องสำหรับภูมิภาคของคุณ
ทดลองได้ครบทุกโมดูลหลัก รวมถึง Kentik Core, NMS, Synthetics, Cloud และ Protect โดยไม่ต้องใช้บัตรเครดิต ข้อจำกัดคือไม่มี Production SLA, Support ระดับ Enterprise และ Data Retention ในช่วง Trial อาจถูกจำกัด
Protect (รวมทุกแผน): DDoS Detection, RTBH Mitigation, FlowSpec, RPKI Analytics

Protect Advanced (Add-on Pro / รวมใน Premier): เพิ่ม Threat Analytics, Botnet Analytics, Mitigation Integration API และ Third-party mitigation กับ Radware, A10, Cloudflare Magic Transit — เหมาะสำหรับ Network ที่ต้องการ Automated Mitigation ระดับสูง
เหมาะมากครับ Kentik มี Add-on "Service Provider Analytics" ที่ออกแบบสำหรับ ISP และ Telco โดยเฉพาะ ครอบคลุม Subscriber Analytics, CDN Analytics, OTT Analytics และ Kentik Market Intelligence — ช่วยทั้งด้าน operational และ revenue optimization สำหรับ Service Provider
Kentik Firehose คือ data export pipeline ที่ช่วยส่ง telemetry data ออกจาก Kentik ไปยัง external systems เช่น Kafka, Amazon S3, Google BigQuery หรือ Splunk เหมาะสำหรับทีมที่มี Data Platform เป็นของตัวเองและต้องการ Custom Analytics นอกเหนือจาก built-in Kentik tools
